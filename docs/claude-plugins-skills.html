MCP Servers

Model Context Protocol servers provide tool access to external services.

Supabase MCP

  • Config: .mcp.json at repo root
  • Package: @supabase/mcp-server-supabase@latest
  • Tools: Direct database queries, schema inspection, table management
  • Auth: Uses SUPABASE_ACCESS_TOKEN from environment
  • Use when: Inspecting the live database schema, testing RLS policies, checking data during debugging

Custom Commands

/manager
File: .claude/commands/manager.md
The primary entry point for all development tasks. Invokes the orchestrator agent which reads its spec from .claude/agents/orchestrator.md and delegates to the appropriate specialist agents.

Usage:

/manager Add pagination to the groups list API

How Plugins Enhance Development

Automated Context Injection

The Vercel plugin uses hooks to automatically inject relevant context:

  • SessionStart: Loads the full Vercel ecosystem knowledge graph on every session
  • PreToolUse: When you read/edit/write files, matching skills are auto-injected based on file patterns (e.g., editing a Next.js file triggers vercel:nextjs)

MCP for Live Data Access

The Supabase MCP server lets agents inspect the actual database schema, test queries, and verify RLS policies — without manually running SQL in a terminal.

Design System Awareness

The .impeccable.md file provides UI agents with the project's design tokens, brand colors, typography choices, and design principles. The frontend-design plugin uses this to maintain visual consistency.
