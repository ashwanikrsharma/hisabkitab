Quick Start

  1. Clone the repo and install dependencies: npm install
  2. Copy .env.example to .env and fill in your Supabase credentials
  3. Start the web app: npm run web
  4. Start the mobile app: npm run mobile

See the Development Guide for full setup instructions.

For AI Agents

All tasks must go through the orchestrator agent (/manager). The orchestrator decomposes tasks and delegates to the appropriate specialist agents.

If you are an AI agent working on this codebase, start with:

  1. AI Agent Workflow — understand how you fit into the development pipeline
  2. Conventions & Standards — mandatory rules you must follow
  3. The relevant domain-specific doc for your task (API, Database, etc.)
