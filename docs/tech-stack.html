Technology Stack

Complete breakdown of every language, framework, database, and tool used in HisabKitab.

Languages

LanguageUsageVersion
TypeScriptAll application code (web, mobile, packages)^5.4.5
SQLDatabase migrations and RLS policiesPostgreSQL 15+ (via Supabase)

TypeScript is configured in strict mode (strict: true, strictNullChecks, noUncheckedIndexedAccess, noImplicitAny) via tsconfig.base.json at the repo root. All apps and packages extend this base config.

Backend / API

TechnologyPurpose
Next.js API RoutesREST API endpoints (src/web/app/api/)
Supabase SSR (@supabase/ssr)Cookie-based auth for web, session management
Supabase JS (@supabase/supabase-js)Bearer token auth for mobile

The same API routes serve both web (cookie auth) and mobile (Bearer token auth). See src/web/lib/auth.ts for the dual-auth requireAuth() implementation.

Database & Storage

TechnologyPurpose
SupabaseManaged Postgres with Auth, Storage, and Realtime
PostgreSQLRelational database (hosted by Supabase)
Row-Level Security (RLS)Data access control at the database level

Key Tables: users, groups, group_members, expenses, expense_splits, settlements, activity_log, agent_metrics, admin_audit_log, analytics_daily

Deployment Model

  • No CI/CD pipeline (no GitHub Actions)
  • Web deploys via vercel CLI command, managed by web-build-deploy-agent
  • Mobile builds via eas build --platform android --local, managed by mobile-build-deploy-agent
  • Vercel project ID: prj_DpZoE0KYMq46v03dRHp3O0qdBW1f
